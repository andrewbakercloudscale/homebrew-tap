# Homebrew tap for Colima Dashboard

```sh
brew install andrewbakercloudscale/tap/colima-dashboard
brew services start colima-dashboard   # start now and at every login
```

Then open http://127.0.0.1:7766. The formula is generated by `scripts/update-tap.sh` in
[colima-dashboard](https://github.com/andrewbakercloudscale/colima-dashboard) on each release.
